# Web Infrastructure Design

This project focuses on designing different web infrastructures for hosting the website `www.foobar.com`.

The goal is to understand how web servers, application servers, load balancers, databases, firewalls, SSL certificates, monitoring systems, and server clusters work together.

## Tasks

### 0. Simple Web Stack

Design a simple web infrastructure using one server containing:

* Nginx web server
* Application server
* Application files
* MySQL database

### 1. Distributed Web Infrastructure

Design a distributed infrastructure using:

* HAProxy load balancer
* Two web/application servers
* MySQL Primary-Replica cluster

### 2. Secured and Monitored Web Infrastructure

Design a secured and monitored infrastructure using:

* Firewalls
* SSL certificate and HTTPS
* Monitoring clients
* HAProxy load balancer
* Multiple servers

### 3. Scale Up

Design a scalable infrastructure using:

* Additional servers
* HAProxy load balancer cluster
* Separate web servers
* Separate application servers
* Separate database servers
